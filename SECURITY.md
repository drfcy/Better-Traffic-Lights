# Security Policy

Better Traffic Lights uses macOS Accessibility permission to read the positions of visible windows and activate their standard close, minimize, and zoom buttons. The app uses Sparkle only to access the project's HTTPS update feed and GitHub Releases. It contains no data collection or telemetry code. Update ZIPs must pass verification with the built-in EdDSA public key.

Please do not disclose unresolved security vulnerabilities in public Issues. Submit reports through the repository's [GitHub Private Vulnerability Reporting](https://github.com/drfcy/Better-Traffic-Lights/security/advisories/new) and include:

- Affected versions;
- Steps to reproduce;
- Potential impact;
- A suggested fix, if available.

After confirming a report, the maintainers will coordinate remediation and the disclosure timeline.

- 潜在影响；
- 建议修复方式（如有）。

维护者确认问题后会协调修复和披露时间。
